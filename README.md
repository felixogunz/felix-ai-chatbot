# Felix AI

Felix AI is a ChatGPT-style AI assistant built with Python, Flask, JavaScript, HTML, CSS, SQLite and the OpenAI API.

## Features

- AI conversations
- Conversation history
- New conversations
- Rename conversations
- Delete conversations
- Search conversations
- Automatic conversation titles
- Streaming AI responses
- Stop generation
- Regenerate responses
- Edit messages
- Markdown rendering
- Code blocks
- Copy code
- Dark and light themes
- Responsive design
- File uploads
- PDF extraction
- DOCX extraction
- Text file extraction
- Image upload framework
- SQLite persistence

## Technologies

- Python
- Flask
- SQLite
- JavaScript
- HTML
- CSS
- OpenAI API
